An all-in-one World Cup 2026 fixture tracker featuring match schedules, score input, automatic group tables, knockout bracket progression, and top scorers.

---

## 🚀 Features

- ✅ Full 104-match schedule  
- ✅ Live score entry  
- ✅ Automatic group table updates  
- ✅ Knockout stage bracket  
- ✅ Top scorers leaderboard  
- ✅ Team player selection  
- ✅ Favorite team highlighting  
- ✅ Timezone support  
- ✅ Fully static (no backend required)

---

## ⚠️ Important

> Scores are stored locally in your browser (localStorage).  
> They are **not shared across devices or users** and may reset if browser data is cleared.

---

## 📦 Tech Stack

- HTML  
- CSS  
- Vanilla JavaScript  
- JSON data
